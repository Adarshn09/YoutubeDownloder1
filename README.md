# YouTube Downloader (Render Deployment)

This is a Flask-based YouTube video downloader web app powered by `yt-dlp`.

## Stack
- Backend: Flask, SQLAlchemy
- Video: yt-dlp
- Frontend: Bootstrap + vanilla JS
- Server: Gunicorn

## Deploying to Render
Render config is in `render.yaml`.

Build steps include installing `ffmpeg`, upgrading `pip`, installing requirements, and upgrading `yt-dlp`.

The app runs with Gunicorn: `gunicorn -w 2 -k gthread -t 180 -b 0.0.0.0:$PORT app:app`

### Recommended environment variables
- `SESSION_SECRET`: auto-generated by Render
- `DATABASE_URL`: provisioned Postgres (free plan) or use default SQLite
- `FLASK_ENV=production`
- `PYTHONUNBUFFERED=1`
- `YTDL_CACHE_DIR=/tmp/ytdl-cache`
- Optional anti-bot helpers:
  - `YTDLP_COOKIES_B64`: base64-encoded cookies.txt (Chrome export)
  - `HTTP_PROXY` / `HTTPS_PROXY`: if you route requests via a proxy

## Notes on YouTube bot detection
- The app sets realistic headers/UAs and tries multiple player clients (android/ios/web/mweb/tv)
- If YouTube still challenges, provide cookies via `YTDLP_COOKIES_B64`
- Audio extraction prefers `ffmpeg` if present; otherwise falls back to M4A

## Health endpoints
- `/health`: simple health check with yt-dlp version
- `/api/version`: app and Python versions
- `/stats`: basic download stats UI
